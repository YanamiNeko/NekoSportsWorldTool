# 二次复查记录

复查范围：先前修复的源码与离线测试、点位缓存/策略/预览/提交调用链、围栏元数据、统计取整和轨迹后处理。此次确认以下遗漏并修正；交付源码与补丁已包含这些修改。

| 遗漏与触发条件 | 修复 | 回归证据 |
|---|---|---|
| 同一锚点更换账号或学校可能复用另一人的点位；失败回退会接受过期缓存；时钟回拨也可能接受未来缓存 | 按账号、学校、区域和锚点隔离；统一校验 300 秒有效期；拒绝过期/未来缓存；旧无作用域缓存自动失效 | 缓存测试覆盖账号、学校、区域、锚点差异，TTL 临界点、未来时间和旧格式 |
| 点位响应含错误码但仍有列表时可能被当成成功；损坏坐标进入缓存 | 检查业务状态与全部坐标后才保存；解密/网络/业务失败直接返回错误 | 成功、限流、空列表和损坏坐标的模拟响应测试 |
| 策略多个已识别列表只读取第一个；损坏的必经点被静默过滤 | 合并去重所有已识别列表，保留首点与顺序；错误坐标或列表格式明确报错 | 多列表、重复点、无效首点、非数组及可选空字段测试 |
| 围栏 GCJ 转换后旧 lon/glon 与新 lng/glng 不一致；单一围栏 id 被推断为区域 id；无围栏时丢失明确的区域 id | 同步坐标别名；只使用显式 runAreaId，独立保留围栏 id；无围栏仍保留显式区域信息 | 坐标重新解析一致、全部别名一致、围栏 id 不代替区域 id、无围栏保留区域 id 测试 |
| 围栏请求/解析失败被当成无围栏继续执行 | 正式流程与预览均传播错误；成功响应中缺少、为 null 或空列表的围栏仍正常处理 | 无围栏与损坏围栏解析测试；核查预览和正式流程错误传播。没有模拟真实 HTTP 传输 |
| 分钟片段独立四舍五入导致总距离丢失，例如 1000 米/180 秒得到 333+333+333 | 使用取整后累计距离的差值，合计为 333+334+333=1000 | 扩展统计测试，含 180 秒和 603 秒，断言分钟片段距离之和等于总距离 |
| 后处理覆盖索引 2 异常点的速度上限；后段随机分类把异常点改成有效点 | 异常点不参与这两项修改 | 固定两个位置为异常点，64 个种子验证其分类及速度保持不变 |
