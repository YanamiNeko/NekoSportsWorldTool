## 验证边界

本次 Windows 本地 `cargo test --all --locked` 已通过：主库 103 项、路网单元测试 5 项、集成测试 7 项；6 项显式网络/设备 smoke 保持 ignored。新增城市与 HTTP 测试无需个人位置数据。真实第三方限流响应、磁盘耗尽、平台授权流程仍需各自的运行环境验证。
