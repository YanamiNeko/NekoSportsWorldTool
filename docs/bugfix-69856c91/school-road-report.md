## 使用方法

1. 解压 Windows 压缩包到可写目录，打开 EXE，登录账号。
2. 在设备信息页确认当前城市与定位锚点。
3. 到「路网」页点击「自动获取学校路网」，在下拉框选择接口返回的校区/围栏，核对地图并勾选「已核对下方围栏属于当前校区」。程序同时切换为真实道路模式，按账号学校编号和服务端围栏获取对应 OSM 道路。
4. 到跑步页设置目标距离并查看预览。目标距离超过校内一圈时，继续沿校内道路重复绕行，不放大围栏。
5. 路网缓存有效期 7 天；需要最新数据时点击「重新下载路网」。以前填写的 OSM 路径仍作为手动来源；点击自动获取后清空该路径并切换自动来源。

## 实现范围

- 使用服务端学校围栏作为范围，BD-09 转回 WGS84 后查询 OpenStreetMap；不依赖学校名称模糊搜索。仅向公共地图服务发送地理查询范围，不发送登录凭证、账号或学校编号。
- 按学校编号及完整围栏散列隔离缓存。过期、未来时间、损坏缓存不使用；失败不会回退到其他学校缓存或经典模式。公共下载设置 45 秒客户端超时、25 秒查询时限及 24 MiB 响应上限。
- 道路整段按所有边界交点分段验证，能发现等距抽样会漏掉的窄缺口。凹形校区和分离校区之间不得跨越校外区域。
- 真实道路模式生成路线（包括手动 OSM 来源）要求有效围栏；仅加载地图无需围栏。保留道路拐点，校内模式关闭切角平滑与 GPS 位移。定时采样跨越拐点时补入经过的拐点，插值累计时间、距离、步数，再统一重建统计；最终校验每个点及每条连线。
- 空路网、围栏内无道路、校外必经点、道路不连通、无法闭合均明确报错。没有自动定位，也不会自动切换经典模式。
- 下载结果绑定请求编号、账号、学校及定位，切换来源/账号后迟到的结果不能覆盖当前路网。小屏路网页可滚动，桌面保留画布。

## 追加六项功能和三项优化

| 项目 | 实现及验证边界 |
|---|---|
| 校区选择与围栏确认 | 仅从实际响应的 campusId/campusName 或围栏名称分组，没有名字时标注“未提供校区名”。确认绑定学校与围栏；围栏变化或学校不匹配时要求重新确认。未接触真实账号验证特定学校接口字段。 |
| 生成前检查 | 展示离路/校外点位、道路连通分量、当前点位顺序完整闭环的最短距离；地图标红问题点。距离不足或道路不可达不生成。此最短值是固定点位顺序的闭环距离，不宣称是任意顺序下的全局最优。 |
| 分圈和进度 | 总距离、计划必经顺序、每次返回起点的圈长及末圈；进度滑块在轨迹上显示当前位置。分圈合计等于目标距离。 |
| 缓存管理 | 显示学校/校区、下载时间、文件大小，可更新当前学校的对应围栏缓存、清除指定缓存，后台载入离线地图及保存的点位/围栏。旧缓存没有上下文时，路线覆盖检查信息可能不足，需在线刷新。离线不能直接提交。 |
| 诊断导出 | 一键写入程序数据目录 diagnostic-时间.json，采用字段白名单，输出错误类别、版本、平台、道路节点/边数量、路线检查摘要。原始错误响应不导出，因此不含未知位置的凭证。实际点击导出后检查文件，另用嵌入假 Token 的错误测试不泄露。 |
| GPX 实际轨迹分析 | 支持标准 GPX trk/trkseg/trkpt（含命名空间和空元素）。本地分析距离、段内用时、平均配速、点位覆盖、越界点及跨界连线，并叠加地图。不同段不相连，缺失/倒退/重复时间不生成虚假配速。采样稀疏时覆盖和越界依赖连线估计，不等同于真实连续定位。 |
| 取消、进度和重试 | 学校请求显示获取围栏、获取点位、下载/读取、校验阶段。取消会使旧编号和结果失效；底层等待中的 HTTP 请求可能持续至结束或超时，正在运行的计算也可能继续至检查点，界面不宣称立即停止。正式准备可取消，提交前原子切换与取消互斥；进入记录提交后不可撤回。失败可重试。 |
| 大路网性能 | 路网地图通过空间索引查询视野内道路，远景适当简化绘制；预览计算在后台，参数变更等待 300 ms 合并、同一时刻只运行一份预览，拖动不重算。离线 OSM 解析也在后台。10000 边测试验证局部视野只返回附近道路且图不变；未提供真机 FPS 基准或任意规模性能保证。显示简化不参与规划和越界判定。 |
| 分类错误 | 网络超时、学校无道路、围栏/校区问题、不可达点位、距离不足、闭环失败、取消分别显示处理建议；下载、预览及正式流程共用分类逻辑。 |

补充回归：校园名称来源及学校隔离、缓存列表/离线读取/安全删除、固定顺序最短距离、GPX 分段与缺失时间、圈长守恒、诊断白名单与实际按钮导出、取消与进入提交互斥、取消下载后的迟到结果、过期/取消预览结果在切换页面后仍会被丢弃、10000 条道路的视野查询。缓存匹配使用约厘米精度的稳定标识，避免 JSON 浮点往返的末位变化造成同一围栏不匹配；实际围栏几何检查使用完整坐标。

首次新增回归发现缓存中浮点坐标的精确相等断言失败，已修复稳定匹配并重新执行最终回归。所有正式交付以最后一次全量检查与 Windows 本机测试为准。原有 CLI 参数、Cargo 依赖和版本号未变；新校区确认字段为可选配置，旧配置可以载入，但真实道路模式现在需要在界面确认有效围栏后运行。


## 2026-10-19 路网加载失败修正

用户反馈 .osm 手动导入和自动加载不可用，且没有看到提示。源码确认：道路模式的手动导入被转交到学校接口流程；自动下载在定位、策略和点位请求之后才执行；状态位于可滚动内容中，可能不在可见区域。

本次改动：本地文件独立后台读取，启动恢复本地路径与重试不要求登录；只接受当前实际支持的 OSM XML，损坏/空/无道路文件显示错误。自动加载先获取学校围栏和路网，成功后先显示地图，再刷新点位；定位未配置、策略或点位失败时保留地图并单独提示预览缺失原因。手动来源刷新学校信息失败也保留已读取地图。状态固定在页面顶部；完成后丢弃迟到的加载进度消息，防止覆盖最终结果，相关消息回归已覆盖。生成校内路线仍要求有效围栏和点位，没有放宽边界检查。

新增 4 项回归：离线点击手动加载及道路可见性；错误文件修正后点击重试；路网已到达而点位仍加载/失败的两阶段消息；各类元数据失败不覆盖成功路网、下载失败仍作为失败处理。UI 覆盖 320×420、360×480、412×600、1100×800，使用含中文与空格的文件路径，实际滚动并检查道路绘制及状态可见性。

最终 GUI 工作区 146 项、无 GUI 工作区 106 项，全部通过；两种全目标编译检查通过。Windows 本机测试与新版 EXE 见 windows-build-report.md。源码包 278 文件、补丁 44 个变更文件，已在干净基线上应用并逐文件比对。

本次使用离线 OSM 样例和模拟结果，没有用户的实际 OSM 文件，也没有通过真实账号访问学校接口或提交成绩；特定学校/网络环境仍需使用新版实际确认。Android 工具链缺失的验证边界不变。


## HTTP 401 与多页面查询结果修正

用户截图明确是 `/api/v1/getGeoFenceForRun` 返回 HTTP 401，提示 Token 有误或服务端缓存中没有 Token。源码确认学校请求会从 Session 读取 Token 并放入签名头；本地原先只检查 uid 和 Token 非空，因此失效会话仍显示已登录，错误分类又误提示检查网络。

已登录学校 API 的 401 现在返回明确的重新登录提示。路网页接收当前会话对应的失败后，清除内存与持久化失效会话，保留设备、配置和已读取地图；小屏展开账号栏，并显示“重新登录”入口。重新登录成功后按现有流程刷新学校围栏与路网。公共地图服务、登录请求自身的失败及 403/429/500 不触发学校会话清除。

路网结果同时绑定请求编号、账号、学校、定位和请求使用的 Token。开始登录时废弃旧路网请求；旧 Token 的迟到 401 不清除新会话。HTTP 中文错误响应采用按字符截断，修复按字节截断可能导致的 panic。

新增 12 项回归覆盖：认证 401 及响应隐私；未认证 401 和其他状态不误清会话；中文错误截断；清除失效会话并保留地图/设备/配置；旧 Token 和旧任务结果不影响新登录；320、360、412 宽度和桌面重新登录按钮实际可点击；共享会话收到一次 401 后停止后续请求且仅通知一次；个人页缓存或部分失败不报更新成功；查询失败不显示空列表成功或无违规；失效后的旧结果被丢弃并保持正在提交的任务状态；错误密码提示可见。

针对第二张截图，跑步记录、违规检查、学期、排行榜、个人页、AI 列表与详情读取均使用带会话代次的后台任务。已失效的会话禁止继续发出新读取请求，已经发出的请求仍可能等待超时；重新登录后忽略旧任务返回。失败结果使用明确错误状态，不再伪装成空列表、无违规或个人页更新成功。已有记录列表可能保留上次数据，状态栏会明确提示刷新失败。

共享会话测试实际启动本机回环 HTTP 模拟服务，检查请求带签名头并返回与截图对应的 401 响应，再验证围栏、违规、记录和个人页请求会被拦截。没有连接真实学校接口。

本次最终 GUI 工作区 161 项、无 GUI 工作区 111 项测试通过，GUI/无 GUI 全目标编译检查通过；Windows 本机测试及启动结果见 windows-build-report.md。源码包 278 个文件、基线补丁 48 个变更文件校验通过。

测试使用离线 OSM 与模拟 HTTP 响应，没有登录真实账号或提交成绩。程序不能使服务端已作废的 Token 重新有效；用户需要在新版点击“重新登录”完成正常认证。此处未声称实际学校接口恢复成功，Android 工具链限制不变。
