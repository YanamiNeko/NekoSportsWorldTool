Windows 测试版首次运行

1. 将整个 ZIP 解压到较短路径，例如 D:\NekoTest。不要在压缩包内直接运行。
2. 先核对 SHA256SUMS.txt；确认下载来源可信后，如文件属性里有“解除锁定”，可勾选后应用。无需关闭系统安全防护。本程序未签名，不能保证消除 SmartScreen 提示。
3. config.example.json 是无账号配置示例。新目录可将它复制为 config.json；升级时请保留原配置，不要覆盖现有账号和设备文件。
4. 首次在设备信息中设置学校附近的定位锚点，再到路网页点击“自动获取学校路网”。没有地图或可达道路时不会自动改用经典模式。
5. 校园地图边界须核对后确认；无边界时无法保证路线始终在校内。地图服务也可能暂时不可用。
6. 身份文件由程序首次运行创建；发行包不应附带他人的 identity.json、session.json、学校缓存或点位。
7. 成绩提交固定模拟安卓；设备页的平台设置仅影响其他请求。自动海拔为模拟数据，填单值将导致零爬升。
8. 本次测试不包含真实成绩提交或 OBS 上传，不能保证服务端达标。P0-2、P1-10 待抓包验证，保持原协议。
9. P0-1 官方 App 最快配速来源仍待验证；P1-8 真实地形海拔尚未接入，本版不能宣称这两项已全部解决。
10. 详情顶部显示 speed、statusInfo、reasonList 原值。CLI 使用 NekoSportsWorldTool.exe record --rrid 123 > record.json，读取该记录的原始详情 JSON；诊断写到 stderr，失败返回非零退出码。需要已有登录状态或记住的登录配置。--version 显示本次构建提交标识。
