# 每公里配速单位修正

用户提供的旧记录截图显示：1.01 公里用时 6:48，配速却显示 0′06″。按截图四舍五入后的距离估算，正确配速约为 6分44秒/公里。

修复前，OBS `laps_json[].avgPace` 写为十进制分钟/公里。把约 6.7 的值当秒格式化，恰好会出现截图中的 0′06″。据此将该字段改为秒/公里；记录级 `speed` 的千分之一分钟/公里、轨迹速度、步幅单位均不变。

此前“1000 米、600 秒得到 avgPace=10.00”的测试沿用了错误的单位假设，现改为 `avgPace=600.00`；展示含义仍是 10分00秒/公里。

新增测试解码实际组装的 gzip/base64 `laps_json`，覆盖完整公里、半公里、短尾段及跨公里插值，确认单位修正不会改变分段用时、累计用时或距离。短尾段用实际距离计算，不能仅凭界面舍入后的 0.01 公里反推精确配速。

本次是基于截图及代码进行的单位修复，未通过真实成绩提交或 OBS 上传测试官方 App 展示。已有服务器记录不会被此修改自动更新。
